# Goals (YYYY-Qn)

> The yardstick. `morning-brief` tags each day's priorities with a goal id, and
> `weekly-second-brain` scores the week against these goals. Work that maps to no goal is
> flagged, not hidden. Idea from mimurchison/claude-chief-of-staff (`goals.yaml`: "Claude
> references it constantly ... scoring tasks").
>
> `current-focus.md` is what is on your mind this week; this file is what you committed to for
> the quarter. Keep 3 to 5 goals. Rewrite at the start of each quarter and move the old ones to
> `## History`.

| Id | Goal (outcome, not activity) | Measure | Target | Status | Link |
|---|---|---|---|---|---|
| G1 | e.g. Checkout conversion up on mobile | mobile checkout CR | +2pp by quarter end | on track | [[project-slug]] |
| G2 | e.g. Hire a senior EM for <team> | offer accepted | 1 by YYYY-MM-DD | at risk | [[person-or-project]] |
| G3 | | | | | |

Status values: `on track` · `at risk` · `off track` · `done` · `dropped`. Only you change them;
skills propose a change in the weekly note.

## Not goals this quarter
- Things that will compete for time and should lose. Skills treat these as "no goal".
